# Manufacturing Roadmap — Aim for Perfection Golf (Internal)

Internal sourcing plan. Not public-facing — the public sees only the Bulk & Events page.

## Phase 1 — Prototype validation

Confirm the spec before requesting quotes:

- [ ] **Material**: zinc alloy (most common for divot tools) / stainless steel / aluminum / brass
- [ ] **Finish**: polished nickel · matte black · gold · antique bronze · enamel fill (current sample: polished + black enamel)
- [ ] **Size & thickness**: measure current sample (approx. 3" tool typical; record exact mm + weight)
- [ ] **Magnet / ball marker**: add a magnetic ball marker seat? (common upsell — decide before tooling)
- [ ] **Packaging**: clear pouch (current) · card backing · gift box · tournament bag insert

## Phase 2 — Supplier search

Target categories:

| Category | Best for | Notes |
| --- | --- | --- |
| Custom golf accessory manufacturers | Purpose-built divot tools | Search "custom divot tool manufacturer OEM" |
| Promotional product manufacturers (domestic) | Fast custom batches | Higher unit cost, easy communication |
| Metal stamping factories | Custom flat shapes | Good economics at volume |
| Die-casting factories | 3D shapes, zinc alloy | Tooling cost, low unit cost |
| CNC metal shops (local) | Premium prototypes | Expensive per unit, fast iteration |
| Challenge coin / enamel pin manufacturers | Same production method | Ideal for enamel fill + raised lettering — the current sample looks like this process |
| Overseas OEM (Alibaba/Made-in-China, verified) | Scale | Lowest unit cost; MOQ + tooling + freight + lead time |

## Phase 3 — RFQ package

Send `RFQ-TEMPLATE.md` with: product photos, logo files, dimensions, material + finish
preference, quantities (50 / 100 / 250 / 500 / 1,000), packaging, lead time, ship-to,
sample request, and explicit asks for tooling cost, unit cost, and MOQ.

## Phase 4 — Vendor comparison

Track every quote in `supplier-comparison.csv`:
supplier · location · MOQ · tooling cost · sample cost · unit cost per tier · lead time ·
packaging options · communication quality · payment terms · risk notes.

Rules of thumb:
- Get 5+ quotes; expect a 2–3× spread on unit cost.
- Always order a paid sample before committing to a batch.
- Payment terms: 30–50% deposit is normal; 100% upfront from an unverified vendor is a red flag.
- Ask for production photos before final payment.

## Phase 5 — Launch production

Start with a low-risk batch:

- **50–100 units** if handmade or domestic
- **250–500 units** if overseas tooling is required (amortize the mold)
- Keep preorders open **only** if lead times are clearly disclosed on the site
- Document landed cost per unit (tooling + units + freight + duties ÷ quantity) — this sets the retail floor

## Pricing strategy (until supplier costs are known)

| Product type | Suggested price |
| --- | --- |
| Standard divot tool | $18–$35 |
| Premium packaged gift version | $30–$50 |
| Custom event/bulk orders | Quote-based |
| Small custom batch | Higher per-unit + setup fee |
| Large custom batch | Lower per-unit, MOQ-based |

Keep custom work quote-based until at least two supplier quotes are in hand.
